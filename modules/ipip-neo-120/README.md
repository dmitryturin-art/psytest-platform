## Перевод

Перевод PsyTest, **не валидирован на русской выборке**. Таблица «оригинал / перевод / обратный перевод / примечание» —
`docs/ipip-translation-review.md` (собрана из `questions.json`). Термины доменов и граней сверены с русскими версиями
NEO и BFI-2 (Калугин и др., 2021); отступления объяснены там же. Готовые русские тексты (psytests.org и др.)
не использовались.

## Что модуль делает

- 120 пунктов, ответ на каждый обязателен; пол и возраст (18–99) спрашиваются перед началом — они выбирают ячейку норм.
- Ячейка: пол × 18–24 / 25–34 / 35–49 / 50+; без возраста — пол, все взрослые; без пола — все взрослые.
- Полосы: перцентиль ≤ 30 «ниже, чем у большинства», 31–69 «как у большинства», ≥ 70 «выше, чем у большинства».
- Страница результата и PDF: пять доменов с перцентилем, полосой и фразой; 30 граней свёрнуты. Карточка кейса
  специалиста дополнительно показывает таблицу сырых баллов.
- Контекст ИИ (07.WP10): домены — `subscales`, грани — `facets`, подпись норм — `norms`; пол и возраст не уходят.
  ИИ-разбор методики выключен, пока владелец не включит его в «Методиках».

## Пересчёт норм

```bash
php bin/ipip-build-norms.php --download --report=/tmp/ipip-norms-report.md
```

Скрипт проверяет SHA-256 файла, сырой файл в Git не попадает (`.gitignore`: `/storage/ipip-raw/`).

# Промпты и образец расширенного ИИ-разбора — Опросник Лазаруса

Статус: справочный задел для этапа 07 (ИИ-отчёты), не реализовано в коде. Наследует `docs/roadmap/PRODUCT_RULES.md` §3 (платный разбор), §6 (ИИ-разборы), §9 (Lazarus). Реализация в backend оформляется как версионированные draft/published промпты по ключу `test | mode | report_kind`; этот файл — исходный материал, а не runtime-артефакт.

## 1. Ключи промптов

По PRODUCT_RULES §6 универсального клинического промпта нет. Для Лазаруса — четыре версии:

| Ключ | Режим | Вид отчёта |
|---|---|---|
| `lazarus \| individual \| professional` | индивидуальный | профессиональное заключение |
| `lazarus \| individual \| clear` | индивидуальный | понятный разбор |
| `lazarus \| pair \| professional` | завершённый парный | профессиональное заключение |
| `lazarus \| pair \| clear` | завершённый парный | понятный разбор |

Бережный язык — свойство только `clear`-промптов. Профессиональные промпты не «смягчаются» общим фильтром.

## 2. Данные, передаваемые ИИ

Передаётся только структурированный расчёт после отдельного явного согласия в checkout (§11). Никаких HTML/PDF/скриншотов, токенов, имён, email. Поля — фактически рассчитываемые в `modules/lazarus/LazarusModule.php`:

### Индивидуальный режим

```json
{
  "test": "lazarus",
  "mode": "individual",
  "items": [
    {"id": 1, "domain": "Общение", "text": "…", "self": 8, "partner_expected": 6, "gap": 2}
  ],
  "totals": {"self": 96, "partner_expected": 84, "max": 160},
  "level": "satisfied",
  "level_name": "Удовлетворённость отношениями",
  "weak_domains": ["Финансы", "Привычки партнёра"],
  "large_perception_gaps": ["Привычки партнёра", "Время вместе"]
}
```

- `items[].self` — оценка респондентом своей удовлетворённости (1–10);
- `items[].partner_expected` — каким респондент ожидает оценку партнёра («за партнёра»);
- `gap` = self − partner_expected;
- `weak_domains` — домены с self ≤ 5; `large_perception_gaps` — домены с |gap| ≥ 3 (пороги платформенные).

### Парный режим (только завершённая пара)

Дополнительно к двум индивидуальным наборам:

```json
{
  "mode": "pair",
  "pair": {
    "overall_agreement_percent": 71.3,
    "items": [
      {
        "id": 4, "domain": "Финансы", "text": "…",
        "p1_self": 4, "p2_self": 8,
        "difference": -4,
        "p1_perception_of_p2": 6, "p2_perception_of_p1": 5,
        "p1_accuracy": -2, "p2_accuracy": 1
      }
    ]
  }
}
```

Незавершённая пара парный разбор не получает — только индивидуальные отчёты каждого партнёра.

## 3. Общий технический слой (одинаков во всех четырёх промптах)

```
Ты получаешь структурированный расчёт опросника супружеской удовлетворённости
А. Лазаруса (16 пунктов, каждый 1–10, двойная оценка: за себя и ожидаемая оценка
партнёра; порог суммарного балла: <80 из 160 — значимая неудовлетворённость).

Жёсткие правила:
1. Используй только переданные показатели. Не выдумывай отсутствующие данные,
   не предполагай пол, возраст, стаж отношений и обстоятельства, которых нет во входе.
2. Разделяй в тексте: (а) измерение — что показал опросник; (б) интегративный
   вывод — что это в совокупности означает; (в) гипотеза — предположение,
   требующее проверки в разговоре или у специалиста.
3. Верни ответ строго в заданной структуре разделов, на русском языке.
4. Не ставь диагнозы и не назначай лечение. Заключение не заменяет консультацию.
5. Не используй формулировки, назначающие виноватого ни одному из партнёров.
6. Числа из данных приводи точно; не округляй и не «улучшай» показатели.
```

## 4. Вариативные части

### 4.1 `professional` (оба режима)

```
Роль: опытный психолог-консультант, готовящий заключение для коллеги-специалиста
или для клиента, запросившего полный профессиональный материал.

Структура ответа:
1. «Результат методики» — суммарные баллы, уровень, таблица/перечень пунктов
   со значениями ниже средней зоны (≤5) и выраженными расхождениями (|gap| ≥ 3).
2. «Профиль по доменам» — содержательная характеристика сильных (≥8), средних
   и слабых зон; в парном режиме — согласованность профилей обоих партнёров,
   точки максимального расхождения собственных оценок и точность предсказания
   партнёром ответов друг друга (perception accuracy).
3. «Клинические гипотезы» — помеченные как гипотезы предположения о возможной
   динамике пары (например, расхождение в финансах как маркер борьбы за контроль),
   без диагностических ярлыков.
4. «Терапевтические мишени» — конкретные темы для проработки в консультировании,
   включая вопросы для обсуждения с парой.
5. «Ограничения» — одномерность методики, самоотчётность, моментальный снимок.

Стиль: профессиональная терминология (домен, самоотчёт, перцептивное расхождение),
плотный текст, 800–1500 слов. Не смягчай профессионально значимый материал.
```

### 4.2 `clear` (оба режима)

```
Роль: бережный объясняющий помощник. Адресат — человек без психологического
образования, который прошёл опросник о своих отношениях.

Структура ответа:
1. «Что показал тест» — общий итог простыми словами, без жаргона.
2. «Что у вас получается хорошо» — сильные зоны и почему они важны.
3. «На что стоит обратить внимание» — слабые зоны и заметные расхождения
   между вашей оценкой и тем, что вы ожидаете от партнёра, объяснённые
   на бытовых примерах.
4. «Что можно сделать» — 3–5 конкретных шагов: о чём и как поговорить
   с партнёром, когда имеет смысл обратиться к семейному психологу.
5. Короткое поддерживающее завершение: результат — не приговор, а снимок,
   который можно изменить.

Стиль: просто, тепло, уважительно, на «вы»; короткие абзацы; термины — только
с мгновенным бытовым пояснением; 600–1000 слов. Не запугивать, не обесценивать
проблемы, не назначать виноватого.
```

### 4.3 Парное дополнение (для обоих видов)

```
В парном режиме добавь раздел «Вы и партнёр глазами друг друга»:
- где ваши оценки совпадают (совместные опоры отношений);
- где расходятся больше всего (разница собственных оценок ≥ 3 баллов);
- кто из партнёров точнее предсказал ответы другого (точность восприятия),
  в нейтральных формулировках: точность восприятия — навык, а не оценка личности.
Запрещено: формулировки «виноват», «неправ», «плохой партнёр», сравнения
«кто лучше». Только факты совпадений и расхождений из переданных данных.
```

## 5. Образец выходного отчёта

**Демонстрационные данные, не реальные:** индивидуальный режим, `clear`.
Fixture: totals.self = 96 (satisfied), слабые зоны — финансы (4) и привычки партнёра (3), крупные расхождения — привычки партнёра (gap −4) и время вместе (gap −3).

---

### Что показал тест

Вы оценили 16 сторон своих отношений, и общая сумма составила **96 баллов из 160 возможных**. Это выше границы в 80 баллов, которая отделяет общую удовлетворённость от заметного неблагополучия. Проще говоря: в целом ваши отношения вас устраивают, но не всё в них гладко — есть две-три темы, которые тянут общий балл вниз.

### Что у вас получается хорошо

Особенно высокие оценки вы дали таким сторонам отношений, как союзничество («мой партнёр в моей команде») и доверие. Это важная опора: когда есть ощущение «мы одна команда» и базовое доверие словам и поступкам партнёра, остальные трудности обычно решаемы через разговор.

Также высоко оценены эмоциональная близость и общение. Это значит, что вам есть с кем и о чём говорить — а это главный инструмент для работы над сложными темами.

### На что стоит обратить внимание

Заметно ниже остальных лежат две темы:

**Финансы — 4 балла из 10.** Вы довольны тем, как вы вдвоём обращаетесь с деньгами, меньше, чем другими сторонами отношений. Возможно, речь о разных подходах к тратам или планированию. Само по себе это очень частая тема в парах, и она хорошо поддаётся обсуждению.

**Привычки партнёра — 3 балла из 10.** Здесь же — самое большое расхождение восприятия: вы оценили эту сторону на 3 балла, а партнёра, как вы полагаете, она устроила бы на 7. Такой разрыв часто означает одно из двух: либо вы считаете, что эта проблема важна только для вас, либо вам казалось, что партнёр не придаёт ей значения. Стоит проверить, так ли это на самом деле — иногда ожидаемая реакция партнёра сильно отличается от реальной.

Похожая картина со временем вместе: себе вы поставили 5, а партнёру «за него» — 8. Похоже, вам хочется проводить время вместе больше, чем сейчас, и вы, возможно, недооцениваете, насколько партнёру это тоже нужно.

### Что можно сделать

1. Выберите спокойный момент и обсудите тему финансов: не «кто виноват», а «как нам удобно договариваться о тратах». Хорошо работает правило: сначала каждый описывает своё видение, потом ищете общее.
2. По привычкам партнёра — честно скажите, что именно вас задевает, вместо того чтобы молчать, исходя из предположения «он(а) всё равно не согласится».
3. Про время вместе — предложите конкретное: например, один вечер в неделю, принадлежащий только вам двоим.
4. Если разговоры о деньгах и привычках снова и снова заходят в тупик или заканчиваются ссорами — это нормальный повод обратиться к семейному психологу, не дожидаясь кризиса.

Помните: этот результат — снимок на сегодня, а не приговор отношениям. Общий балл говорит скорее «скорее благополучно с проблемными зонами», и такие зоны есть у большинства пар.

*Разбор подготовлен автоматически на основе ваших ответов. Он носит ознакомительный характер, не является диагнозом и не заменяет консультацию специалиста.*

## 6. Тестирование промптов

Промпты проверяются на обезличенных fixtures до публикации (§6): минимум три случая на каждую комбинацию ключа — удовлетворённый профиль, неудовлетворённый (<80), профиль с крупными perception gaps; для pair — согласованное расхождение и высокая согласованность. Проверка: отсутствие выдуманных данных, наличие дисклеймера, отсутствие виноватых в pair-варианте, попадание в заданную структуру и объём.

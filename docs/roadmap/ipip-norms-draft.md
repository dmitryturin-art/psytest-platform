Статус: завершено 08.10.2026 (все 5 разделов). Код и git не трогались. Файлы данных (IPIP120.dat 95 МБ и т.п.)

## 1. Открытые датасеты с ответами по пунктам

### 1.1 Johnson's IPIP-NEO data repository (OSF) — основной источник

- URL: https://osf.io/tbmh5/ («Johnson's IPIP-NEO data repository», создан 22.09.2015, public).
  Подкомпонент с данными статьи 2014: https://osf.io/wxvth/ ; ключи: https://osf.io/ycvdk/.
- Проверено через `api.osf.io/v2/nodes/wxvth/files/osfstorage/`: файлы `IPIP120.dat` (94,7 МБ, ASCII),
  `IPIP120.por.zip` (SPSS, 42,9 МБ), кодбук `DAT120.doc` (37 КБ), а также `IPIP300.dat` (102,9 МБ) / `DAT300.doc`.
  Вики компонента: «IPIP120.dat contains 619,150 cases of item responses to the IPIP-NEO-120».
- В `ycvdk`: `IPIP-NEO-120 Scoring Tool.xls`, `IPIP-NEO-ItemKey.xls`, печатная анкета, и **папка
  «IPIP-NEO-300 Profile Sheets, UK Norms»** (британские нормы для 300-пунктовой версии; содержимое папки не открывал).
- Переменные (по кодбуку, пересказанному в описании Kaggle-зеркала и подтверждённому схемой HF-копии):
  `CASE, SEX (1=м, 2=ж), AGE, SEC, MIN, HOUR, DAY, MONTH, YEAR, COUNTRY, I1…I120`; пропуск = 0;
  **реверсные пункты уже перекодированы** в момент сбора (суммировать без перекодировки — важно для расчёта норм
  и для сверки с нашим scoring, где реверс делаем сами). `COUNTRY` — строка, обрезанная до 9 символов
  («Russian F», «Kazakhsta», «South Afr»).
- Выборка (Johnson 2014, JRP 51:78–89, раздел Study 2, проверено в тексте PDF): веб-сайт автора, 2001–2011;
  до чистки 690 863, после 619 150 (248 258 м, 370 892 ж), средний возраст 25,2 (SD 10,2). Чистка по критериям
  Johnson (2005): дубликаты, невнимательные ответы, много пропусков, низкая внутренняя согласованность.
  По вторичным источникам ~72 % — США, 241 страна, возраст 10–99.
- **Таблиц норм (средние/SD по полу и возрасту) в статье 2014 нет** — проверено по тексту: таблицы 1–4 это пункты,
  alpha, корреляции с NEO PI-R/критериями, факторная структура. Автор пишет о намерении передать ответы
  «in the public domain for analyses by interested members of the personality research community».
- **Лицензия: на OSF не указана** (`node_license: null` у tbmh5, wxvth, ycvdk). Формально это «нет лицензии»,
  а не CC0. Основание для использования: заявление автора в статье о передаче в public domain + public domain
  самих пунктов IPIP + широкая практика (NovoPsych построил на этих данных коммерческие австралийские нормы,
  Kajonius & Johnson 2019 и др.). Вывод: вычислять и публиковать **агрегаты** (перцентильные таблицы) — низкий
  риск; республиковать сырой файл — не нужно и не стоит. **Рекомендация: одно письмо Johnson
  (j5j@psu.edu, адрес из PDF статьи) с просьбой подтвердить, что производные нормы с атрибуцией допустимы** —
  это закрывает юридический вопрос за один шаг; до ответа — атрибуция «Johnson, J. A. (2014); data: osf.io/tbmh5».

### 1.4 Юридический итог по разделу 1

- Самый сильный довод за допустимость: **Twomey & Johnson (2022)**, *European Journal of Psychological Assessment* 38(6):432–439,
  DOI 10.1027/1015-5759/a000644 (PDF открыт с сайта Johnson в PSU: bpb-us-e1.wpmucdn.com/…/UKnorms.pdf). Сам Johnson как соавтор
  пишет, что таблицы норм из его репозитория свободны, «there is no need to ask for permission to modify them», и даёт
  инструкцию, как строить такие нормы **для других стран, возрастов и с разделением по полу**. То есть построение
  производных национальных норм из tbmh5 прямо предусмотрено автором данных.
- Письмо Johnson остаётся желательным (вежливость и evidence в реестре), но не блокирует релиз.
- Kajonius & Mac Giolla (2017), PLOS ONE 12(6): e0179646, CC BY 4.0: 22 страны с N>1000 из того же датасета (19–69 лет,
  пропуски <1 % заменялись средним по пункту). Россия в критерий N>1000 не попадает (в тексте статьи не упоминается). Ключевой вывод статьи:
  вклад страны в баллы черт **< 2 % дисперсии**, страны различаются менее чем на 0,5 SD — довод за международную норму
  как временную. S1 Table — сырые средние/SD 30 фасетов по странам (CC BY) — годится как sanity-check.

## 4. Метод: предварительные нормы на нашей стороне

### 4.1 Подготовка данных (скрипт в `tools/`, не в рантайме; результат — json-таблица в модуле)

1. Источник: `IPIP120.dat` с OSF (wxvth, файл q9jrh, 94,7 МБ) + `DAT120.doc` (кодбук). Для расчёта файл нужно скачать
   (в этой сессии не скачивал). Записать SHA-256 файла в evidence, чтобы нормы были воспроизводимы.
2. Фильтры (как у NovoPsych + Kajonius, все параметры фиксируются в README таблицы):
   - анкеты с любым пропуском (0) исключить (вариант Kajonius: ≤1–2 пропуска заменить средним по пункту — даёт больше
     данных, но усложняет воспроизводимость; для R1 — строгий вариант без пропусков);
   - возраст 18–90 (взрослые; клиенты платформы взрослые), пол 1/2;
   - **реверс не применять повторно**: в файле реверсные пункты уже перекодированы. Golden-тест должен сверять наш
     scoring с этим соглашением (наша сумма по сырым ответам с реверсом == сумма по файлу);
   - опционально: исключить длинные серии одинаковых ответов (>7–10 подряд, как Kajonius), Johnson уже чистил.
3. Баллы: фасет = сумма 4 пунктов (4–20), домен = сумма 24 пунктов (24–120). Именно те же суммы, что в нашем scoring.
4. Ячейки: пол (2) × возраст. Предложение: **18–24, 25–34, 35–49, 50+** (8 ячеек). Johnson-выборка молодая (M=25),
   поэтому 50+ будет самой тонкой ячейкой — фактические n в разделе 4.4.
5. Перцентиль для каждого сырого балла (4–20 для фасета, 24–120 для домена) в каждой ячейке: mid-rank
   `PR = 100 × (count(< x) + 0,5 × count(= x)) / n`. Для доменов при больших n этого достаточно; для узких ячеек — сглаживание
   (`cNORM` в R, как NovoPsych, — непрерывное нормирование по возрасту без жёстких границ; это лучше, но добавляет R в tooling).
   Для R1 достаточно эмпирических mid-rank перцентилей по ячейкам с n≥ порога; `cNORM` — улучшение второго шага.
6. Полосы для показа: **≤30 низкий / 31–69 средний / ≥70 высокий** (как NovoPsych; совпадает с текущей идеей брифа)
   либо 5 полос Twomey & Johnson (очень низкий 7 % / низкий 24 % / средний 38 % / высокий 24 % / очень высокий 7 %).
   Для клинициста удобнее 5 полос + сам перцентиль; решать владельцу.
7. Хранить в `modules/ipip/norms/johnson2014-intl.json`: метаданные (источник, DOI, SHA-256, фильтры, дата расчёта,
   n по ячейкам) + таблица `cell → scale → raw → percentile`. Отдельный contract-тест: монотонность перцентилей,
   полнота диапазонов, n ячейки ≥ порога, совпадение с пересчётом скриптом.

### 4.2 Минимальный n на ячейку

Стандартная ошибка перцентильного ранга около p: `SE ≈ 100·√(p(1−p)/n)`. Для p=0,30 (граница полос):
n=100 → ±4,6 п.; n=200 → ±3,2; n=400 → ±2,3; n=1 000 → ±1,4. Хвосты (p=0,07) точнее по абсолютной величине, но
относительная ошибка больше. Плюс дискретность: у фасета всего 17 возможных значений, поэтому перцентили фасетов
«прыгают» ступеньками независимо от n.

Правило для платформы: **ячейка пол×возраст используется при n ≥ 300; при 100 ≤ n < 300 — с пометкой «малая
ячейка»; при n < 100 — откат на пол без возраста (или на общую норму).** Для международной выборки это неактуально
(тысячи на ячейку), для русской подвыборки и своих норм — ключевое.

### 4.5 Накопление собственных норм PsyTest

**Что хранить** (отдельная таблица `ipip_norm_samples`, без связи с аккаунтом, клиентом, сессией, IP, временем до минуты):
- 120 ответов (1–5) + версия перевода (`translation_version`, хэш текстов пунктов — нормы привязаны к версии перевода);
- пол (м/ж/не указан), **возрастная группа** (не дата рождения, не точный возраст — достаточно 5-летних групп),
  страна/язык интерфейса (RU), контекст: `self_guest` / `therapist_assigned` (клиенты терапевта — клиническая
  или «обращающаяся за помощью» выборка, их **нельзя смешивать** с общей нормой; хранить флаг и считать отдельно);
- метрики качества: время прохождения (бакетом), максимальная серия одинаковых ответов, индекс противоречивости
  (пары противоположных пунктов — в Johnson 2014 есть 29 пар для Acquiescence Index), флаг повторного прохождения
  (только хэш-признак «уже проходил с этого устройства/аккаунта» без хранения идентификатора).
- Квартал сбора (для контроля дрейфа), без точной даты.

**Согласие** (отдельная необязательная галочка, по умолчанию выключена; отказ не влияет на результат):
> «Разрешаю использовать мои ответы в обезличенном виде для расчёта русских норм этого теста. Сохраняются только ответы,
> пол и возрастная группа — без имени, почты и связи с моим профилем. Удалить такие данные по отдельности после
> сохранения невозможно, так как они не связаны с вами.»
Формулировку согласовать с `PRODUCT_RULES.md` §10–11 (в этой сессии не читал) и с 152-ФЗ: обезличенные данные вне
режима ПДн только при реальной невозможности переидентификации (поэтому — группы, а не точные значения, и никаких
свободных полей). Для `therapist_assigned` — согласие самого клиента, не терапевта.

**Когда переключаться на свои нормы:**
1. Психометрический этап (до норм): при N ≥ 300–500 валидных русских анкет — α по фасетам/доменам, CFA/ESEM на уровне
   доменов, сравнение средних с Johnson и с BFI-2 RU (Калугин 2021) — подтверждает, что перевод работает.
2. Нормы: переключать **ячейку** на русскую норму, когда в ней ≥ 300 валидных анкет `self_guest` (по порогу 4.2);
   до этого — международная норма с подписью. При ~8 ячейках это ≥ 2 400 анкет, реально 3–5 тыс. из-за неравномерности
   (молодые женщины набираются быстрее, мужчины 50+ — медленнее всех).
3. Пересчёт по расписанию (раз в квартал), каждая таблица норм версионирована; в результате указывается версия норм.
   Результаты в истории не пересчитываются молча — хранится версия нормы, по которой показан перцентиль.
4. Решение о переключении — владельца, с отчётом (n по ячейкам, α, сдвиг средних vs Johnson в d).

## 5. Рекомендация для релиза 1

**Путь:** перцентили по полу × возрасту из открытого датасета Johnson (OSF tbmh5), **все страны**, взрослые 18+,
полные анкеты; русская подвыборка Johnson **не** используется как норма (слишком мала, см. 4.4, и отвечала на
английском) — только как контрольное сравнение в отчёте пакета. Параллельно с первого дня — накопление собственных
обезличенных норм русского перевода с отдельным согласием (4.5) и переключение по ячейкам при n ≥ 300.

Почему не «только США»: США = 72 % и так доминируют; «все страны» честнее подписывать как «международная», а разница
США/все страны для доменов мала (d < 0,2 типично для западных стран по Twomey & Johnson). Можно посчитать оба варианта
и выбрать после сравнения — это решение владельца, не инженерное.

Почему это «не недоделано»: это ровно та процедура, которую автор методики сам описал и одобрил для национальных норм
(Twomey & Johnson 2022), и та же, по которой построены коммерческие нормы NovoPsych. Недоделанным остаётся одно —
**нормы именно русского перевода**, и этого не может закрыть никакой внешний источник: опубликованных русских норм
IPIP-NEO-120 нет, а единственная русская адаптация IPIP-NEO (Стрижова и др. 2019) — другой набор пунктов и
корпоративная, на 80 % мужская выборка.

**Шаги пакета норм (до кода модуля или вместе):**
1. Скачать `IPIP120.dat` + `DAT120.doc` с OSF (≈95 МБ; нужно разрешение владельца на скачивание), записать SHA-256.
2. Скрипт расчёта (Python/PHP в `tools/`), фильтры из 4.1, вывод json + отчёт n по ячейкам и сравнение
   все страны / США / Россия (средние доменов, d).
3. Письмо Johnson (j5j@psu.edu): уведомить и попросить подтвердить использование производных норм в бесплатной
   платформе с атрибуцией. Не блокер (см. 1.4).
4. Решение владельца: 3 или 5 полос; показывать ли фасеты гостю.
5. Таблица `ipip_norm_samples` + согласие + флаг контекста — вместе с модулем, чтобы набор начался с первого дня.

**Риски (честно):**
- **Неэквивалентность перевода.** Перцентиль по английской норме для русского текста предполагает одинаковую
  «трудность» пунктов. Не проверено. Отдельные пункты могут сдвигаться на 0,3–0,5 балла из-за формулировки — для
  фасета из 4 пунктов это заметный сдвиг перцентиля. Митигация: подпись, ранний психометрический отчёт при N≈300–500,
  возможность перевыпустить нормы.
- **Выборка Johnson** — самоотобранные англоязычные интернет-пользователи 2001–2011, молодые (M=25); старшие возрастные
  ячейки тоньше; когортный сдвиг за 15–25 лет неизвестен.
- **Клиенты терапевта ≠ популяция.** Повышенный N у обращающихся за помощью ожидаем; сравнение с нормой
  здоровой популяции — это корректная цель, но в собственные нормы их смешивать нельзя.
- **Лицензия данных формально не указана на OSF.** Риск низкий (заявления автора в двух статьях), закрывается письмом.
- **Фасеты дискретны (17 значений)** — перцентиль фасета грубый; показывать полосой, а число — специалисту.
- **Своя норма наберётся не скоро**: ≥2 400–5 000 валидных анкет при неравномерных ячейках; на это уйдут месяцы/годы
  в зависимости от трафика. До этого — международная норма с подписью, без иллюзии «русских норм».

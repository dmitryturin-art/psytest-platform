# Готовые переводы и нормы для шкал IPIP помимо NEO-120 — обзор (11.10.2026)

Вопрос владельца: «возможно, кто-то уже сделал работу за нас» — есть ли готовые (а) русские переводы и адаптации и
(б) опубликованные нормы или открытые наборы ответов для шкал IPIP помимо NEO-120 и для CAT-PD-SF v1.1.

Как проверялось. Страницы IPIP (переводы, нормы, разрешение, таблицы шкал, CAT-PD-SF) прочитаны напрямую. По архивам
данных прочитаны карточки, условия использования и списки файлов; из мелких служебных файлов (описания, справочники,
заголовки таблиц, файл демографии ESCS на 24 КБ) прочитано содержимое, чтобы понять состав. **Большие наборы данных не
скачивались.** Что не удалось проверить, помечено «не проверено». То, что уже разобрано в
[ipip-norms-draft.md](ipip-norms-draft.md) и [../ipip-norms-review.md](../ipip-norms-review.md) (набор Johnson для NEO-120,
NovoPsych, британские нормы, BFI-2, 5PFQ, NEO-PI-R, русский IPIP-NEO Стрижовой и соавторов), здесь не повторяется.

---

## 1. Короткий вывод

**Русских переводов мало, и почти всё — «Большая пятёрка».** Кроме NEO уже есть:

- русский IPIP-50 (O. Hypponen, студенческая работа) — **выложен прямо на сайте IPIP**, текст пунктов открыт;
- русские маркеры Большой пятёрки на 100 пунктов (Князев, Митрофанова, Бочаров, 2010, «Психологический журнал») —
  единственный рецензируемый русский IPIP-опросник кроме NEO; текст статьи в открытом доступе не найден;
- русская версия IPIP-шкал эмоционального интеллекта по Barchard (Князев, Митрофанова, Разумникова, 2012, по данным
  psytests.org) — **единственная найденная русская IPIP-шкала вне Большой пятёрки**, и она попадает в нашу область
  «эмоциональная регуляция». Публикация и психометрика не проверены.

**Русской версии CAT-PD / CAT-PD-SF нет нигде** — ни в публикациях, ни на сайте IPIP, ни у авторов методики, ни на
psytests.org (у них только английская версия). Перевод CAT-PD-SF придётся делать самим. На русском психометрически
изучена только **краткая форма PID-5** (Кустов и соавт., 2022) — но PID-5 принадлежит Американской психиатрической
ассоциации и в коммерческий продукт без её разрешения не встраивается.

**Нормы.** Готовых таблиц норм по полу и возрасту для шкал IPIP помимо NEO **никто не публикует** — сайт IPIP прямо
советует строить свои. Но **открытые наборы ответов, из которых их можно посчитать, есть**, и это главная находка:

1. **Eugene-Springfield Community Sample (ESCS)** — тот самый набор, на котором Голдберг проверял почти все шкалы
   IPIP. Лежит открыто, **лицензия CC0** (общественное достояние, можно всё, включая коммерцию). 1 134 взрослых жителя
   Орегона, 18–89 лет, средний возраст 50, 531 мужчина и 603 женщины; ответы на **2 539 пунктов IPIP**. В нём есть
   пункты именно для наших областей: шкала диссоциации, самооценка, локус контроля, оптимизм, перфекционизм
   (из опросника обсессий), доминирование (CPI), отчуждённость (MPQ), эмоциональный интеллект и др. Минус: выборка
   небольшая (по каждой шкале ~450–750 человек), американская, почти целиком белая, ответы 1994–2004 годов.
   Годится для ориентировочных норм **по полу** (и максимум 2–3 широким возрастным группам), а не для мелкой сетки.
2. **SAPA Project** (Condon, Revelle) — огромные открытые архивы, **CC0**. Набор 2013–2017 годов (~127 тыс.
   человек) содержит 696 пунктов IPIP из 92 шкал, включая IPIP-HEXACO (там есть «зависимость» и «перфекционизм»),
   IPIP-MPQ («отчуждённость», «социальное влияние», «агрессия», «поглощённость», «благополучие»), полный IPIP-NEO-300.
   **Но** каждый человек отвечал лишь на случайные ~86 пунктов из 696, поэтому балл по шкале у отдельного человека
   почти никогда не посчитать. Из этих данных можно оценить только среднее и разброс шкалы в группе (по полу и
   возрасту) расчётным путём, а не «настоящие» процентили. Это рабочий, но более сложный и менее наглядный путь.
3. **Данные CAT-PD на OSF** (лаборатория Simms, Университет Буффало) — **ответы на все 216 пунктов CAT-PD-SF** с
   полом, возрастом и типом выборки (общая популяция / пациенты / студенты), объединённая выборка около 4 000 человек.
   Это ровно то, что нужно для норм CAT-PD-SF. **Но лицензия на OSF не указана** — данные выложены для проверки
   статей, а не для повторного использования. Нужно письменное разрешение авторов (или хотя бы ответ на вопрос),
   прежде чем строить на них нормы. Это пункт для письма, а не для скачивания.
4. **OpenPsychometrics** — IPIP-HEXACO на 240 пунктов (22 786 человек, со страной) и маленький набор с IPIP-шкалой
   доминирования (1 005 человек). Лицензия не указана, сайт IPIP пишет «на свой страх и риск».

**Русских открытых наборов ответов на IPIP-шкалы не найдено** (OSF, Zenodo, Dataverse, поиск по публикациям).
Русские респонденты есть только внутри международных наборов (Johnson; возможно, OpenPsychometrics), отвечали они
по-английски.

**Итог в одну строку:** перевод почти всего придётся делать самим (кроме IPIP-50/100 и шкал эмоционального интеллекта,
где есть от чего оттолкнуться); ориентировочные американские нормы по полу для большинства шкал раздела 5Б можно
посчитать без своей выборки из ESCS (CC0); для CAT-PD-SF нормы реальны только после письма авторам данных.

### 3.2. Для каких шкал реальны нормы без своей выборки

Оговорка для всех строк: нормы будут **американские**, на английской форме, и для ESCS — с небольшими группами.
В подписи результата это говорится прямо, как сейчас для NEO-120. Наличие пунктов конкретной шкалы в ESCS
подтверждено таблицами сайта IPIP, но **точное число ответивших по каждой шкале — не проверено** (выяснится после
скачивания: волны анкет отвечали разные люди).

| Область брифа 5Б | Кандидат IPIP | Откуда нормы | Насколько реально |
|---|---|---|---|
| Диссоциативные переживания | IPIP-шкала диссоциации (Goldberg, 1999, на основе Curious Experiences Survey): полная, краткая, деперсонализация, поглощённость, амнезия | ESCS | **Да, по полу.** Лучший случай: шкала родилась именно на этой выборке |
| Самооценка и локус контроля | IPIP-аналоги шкалы самооценки Розенберга и локуса контроля Левенсон (внутренний, «влиятельные другие», случай) | ESCS | **Да, по полу** |
| Ресурсы и сильные стороны | IPIP-оптимизм (аналог LOT-R); IPIP-VIA (24 сильные стороны); IPIP-MPQ «благополучие» | ESCS; для MPQ ещё SAPA | **Да, по полу** для оптимизма и MPQ; для VIA — после проверки, кто отвечал |
| Перфекционизм и ригидность | IPIP-HEXACO «перфекционизм»; IPIP-шкалы по опроснику обсессий (стремление к порядку; перфекционизм и навязчивые мысли); CAT-PD «перфекционизм» и «ригидность» | ESCS (обсессии); SAPA, OpenPsychometrics (HEXACO); CAT-PD — только данные Simms | Да для IPIP-шкал; для CAT-PD — после письма |
| Доминирование и подчиняемость | IPIP-аналог CPI «доминантность»; IPIP-MPQ «социальное влияние»; CAT-PD «доминирование» и «подчиняемость» | ESCS, SAPA; CAT-PD — данные Simms | Да для IPIP-шкал; для CAT-PD — после письма |
| Недоверие и отчуждённость | IPIP-MPQ «отчуждённость»; CAT-PD «недоверие» | ESCS, SAPA; CAT-PD — данные Simms | Да для MPQ; для CAT-PD — после письма |
| Зависимость и потребность в поддержке | IPIP-HEXACO «зависимость»; IPIP-TCI «зависимость от вознаграждения»; CAT-PD «неуверенность в отношениях», «подчиняемость» | SAPA, OpenPsychometrics (HEXACO); ESCS (TCI, 501 человек; IPIP-HEXACO построен Ashton, Lee, Goldberg (2007) по данным ESCS, так что пункты там, вероятно, есть — не проверено); CAT-PD — данные Simms | Да, но для HEXACO через SAPA — только расчётные средние и разброс |
| Эмоциональная регуляция | IPIP-шкалы эмоционального интеллекта Barchard; CAT-PD «эмоциональная лабильность» | ESCS (EI); CAT-PD — данные Simms | Да для EI по полу (432 ж / 317 м) |
| CAT-PD-SF целиком (33 шкалы) | — | Только данные лаборатории Simms на OSF | **Технически да** (216 пунктов + пол + возраст + тип выборки, ~4 000 человек, часть — пациенты). **Юридически — после письма** |

Чего без своей выборки не получится нигде: **русских** норм для любой из этих шкал и мелкой сетки пол × возраст
(как у NEO-120) для чего-либо, кроме CAT-PD при согласии авторов. Для ESCS разумно ограничиться «по полу» или
«по полу и двум возрастным группам» с честной подписью.

### 3.3. Какие переводы взять за основу

- **Эмоциональный интеллект (Barchard)** — найти статью Князева, Митрофановой, Разумниковой (2012) и написать
  Г. Г. Князеву (он сам указан на сайте IPIP как переводчик и открыт к сотрудничеству): попросить разрешение
  использовать их формулировки со ссылкой. Если откажет или не ответит — свой перевод.
- **IPIP-50 Hypponen и BFFM-100 Князева** — только для сверки формулировок: как русскоязычные авторы передавали
  типичные для IPIP короткие фразы. В батарею не входят.
- **CAT-PD-SF, диссоциация, самооценка, локус контроля, оптимизм, MPQ- и HEXACO-шкалы** — **готовых русских
  переводов нет**, переводим сами по правилу линии O2 (владелец читает перевод до выкладки). Пункты IPIP —
  общественное достояние, разрешение не нужно. Часть пунктов CAT-PD-SF (из 216) написана авторами CAT-PD, а не взята
  из исходного банка IPIP; сейчас они опубликованы в каталоге IPIP и подпадают под его разрешение, а авторы
  дополнительно пишут, что форма бесплатна для исследователей и клиницистов. Отдельной лицензии на CAT-PD на их
  сайте нет (не проверено, нет ли ограничений в руководстве).
- **PID-5 (русские краткие формы)** — не брать: права у APA. Можно упоминать в паспорте CAT-PD-SF как
  «аналог, изученный на русских пациентах».
- **psytests.org** — не брать ни одного текста: права на их переводы у них, а для CAT-PD у них только английский.

### 3.4. Что остаётся только для копилки

- Любые **русские** нормы — только из собственной копилки ответов PsyTest (D-078).
- Сравнение русских ответов с американскими по каждой новой шкале — тоже из копилки, по мере накопления.
- CAT-PD-SF, если авторы не ответят или откажут: показывать сырые средние баллы шкал без процентилей, с подписью
  «нормы не установлены».

## 4. Что не проверено

- Тексты статей Князева и соавт. (2010, 2012): выборки, надёжность, средние.
- Психометрика русского IPIP-50 Hypponen (вероятно, не публиковалась).
- Точное число ответивших по каждой шкале в ESCS и есть ли в ESCS пункты IPIP-HEXACO и IPIP-VIA.
- Состав и коды типа выборки в данных CAT-PD на OSF; число жителей без психиатрической помощи в этих данных.
- Есть ли пол и возраст в наборе IPIP-HEXACO у OpenPsychometrics; сколько там респондентов из России.
- Условия HEXACO-PI-R для коммерческого использования (не перепроверялись).
- Точная выборка в статье Кустова и соавт. (2022) по PID-5-BF.
